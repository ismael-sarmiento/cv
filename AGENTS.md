## Rules

- Static site for GitHub Pages: no backend, no framework, no API keys. The only build step is `tools/build.py`.
- Never edit `index.html` or `en/index.html` by hand: change `data/content.json`, `js/`, `css/` or the build, then
  `python3 tools/build.py <new-version>`.
- Use the shared design system (`/assets/ds/` in the portada repository) for tokens, components, the signature and Alan.
  A change that belongs to every site goes there, not here.
- Keep ES/EN parity and check light and dark, 360 px to desktop, before publishing; run `tools/qa/flows.js`.
- Current position: Head of Data Management at Savana. "Lead Data Engineer" stays in the career path and keywords (SEO).
- Important changes to product, tone, naming, SEO or structure update the stable layer and the dated log of
  `.private/PROJECT_CONTEXT.md`.
- Branch: `main`, published by GitHub Pages. Publishing from this machine is done through the GitHub web interface.
- Analytics: Cloudflare Web Analytics beacon (real token, allowed by the CSP).
